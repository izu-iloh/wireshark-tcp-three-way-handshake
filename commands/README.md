# commands/

Reference command files for the lab. These are text references, not scripts to run as a single batch. Commands must be executed in the correct VM, Mininet prompt, or H1/H4 terminal as described in `../COMMANDS.md`.

- `part1-prepare-and-capture.txt` — topology, host terminals, web server, browser, and packet capture.
- `part2-wireshark-analysis.txt` — open the capture and inspect the TCP handshake.
- `part3-tcpdump-and-cleanup.txt` — read packets and shut down the lab.
