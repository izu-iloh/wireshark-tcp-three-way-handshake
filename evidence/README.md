# evidence/

Store supporting evidence collected during your own execution of the lab.

- `captures/` is for the packet capture produced in Part 1, if you decide it is safe and appropriate to share.
- Screenshots belong in the top-level `screenshots/` directory.
- Written packet observations and reflection answers belong in `docs/`.

Packet captures may expose network metadata or sensitive content. Review them before sharing. Capture files are ignored by Git by default; remove or adjust the relevant `.gitignore` rule only if you intentionally decide to publish a sanitized capture.
