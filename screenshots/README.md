# screenshots/

Place screenshots that you personally capture while completing the lab in this directory.

## Naming convention

Use the task ID and a short description:

`<PART>-<TASK>-<description>.png`

Examples:
- `P1-01-mininet-topology.png`
- `P2-03-client-syn.png`
- `P3-02-tcpdump-three-packets.png`

The full task-by-task list and required content are in `../EVIDENCE_CHECKLIST.md`.

## Screenshot guidance

- Capture the relevant terminal, browser, or Wireshark view.
- Ensure commands, packet fields, and output are legible.
- Avoid showing passwords, private browsing information, or unrelated traffic.
- Do not add fabricated or sample screenshots. This directory starts empty intentionally.
